### 2. VSCode — основной редактор

**Почему VSCode?** Это бесплатный, быстрый и самый популярный редактор среди фронтенд-разработчиков. Он имеет огромное количество расширений и отличную поддержку TypeScript «из коробки».

**Обязательный набор плагинов (установи все):**

| Плагин | Назначение | Источник |
|--------|------------|----------|
| **ESLint** | Подсвечивает ошибки стиля кода и потенциальные баги в реальном времени. Интегрируется с конфигом ESLint. | marketplace.visualstudio.com |
| **Prettier** | Автоматически форматирует код при сохранении. Убивает споры в команде о том, ставить точку с запятой или нет. | marketplace.visualstudio.com |
| **Tailwind CSS IntelliSense** | Автодополнение классов Tailwind, подсветка синтаксиса, подсказки по цветам. | marketplace.visualstudio.com |
| **Error Lens** | Показывает ошибки и предупреждения прямо в тексте редактора (не в отдельной панели). Ускоряет отладку в разы. | marketplace.visualstudio.com |
| **GitLens** | Показывает, кто и когда написал каждую строку кода. Незаменим при работе в команде. | marketplace.visualstudio.com |
| **Vitest Runner** | Запускает тесты прямо из редактора, показывает их статус. | marketplace.visualstudio.com |

**Настройка Prettier:**

Создай в корне проекта файл `.prettierrc`:

```json
{
  "semi": true,
  "singleQuote": true,
  "tabWidth": 2,
  "trailingComma": "es5",
  "printWidth": 100,
  "endOfLine": "auto"
}
```

И настрой VSCode так, чтобы Prettier форматировал код при сохранении:
- Открой настройки (`Cmd+,` или `Ctrl+,`)
- Найди `Editor: Format On Save` и включи.
- Найди `Default Formatter` и выбери `Prettier`.

### 3. Node.js — рантайм для JavaScript

**Что это?** Node.js — это среда выполнения JavaScript вне браузера. Она нужна, чтобы запускать сборщики (Vite), пакетные менеджеры (pnpm) и скрипты.

**Какая версия нужна?** Node.js 20 LTS или выше. LTS (Long Term Support) — это версии, которые поддерживаются годами и считаются стабильными.

**Проверка:**
```bash
node -v
```
Если версия ниже 20 — обнови через официальный сайт nodejs.org или через nvm (Node Version Manager).

**Источник:** nodejs.org — официальный сайт.

### 4. pnpm — пакетный менеджер

**Что такое пакетный менеджер?** Это инструмент, который скачивает и устанавливает библиотеки (зависимости) для твоего проекта из реестра npm.

**Почему pnpm, а не npm?**

| Характеристика | npm | pnpm |
|---------------|-----|------|
| Скорость установки (cold install) | базовый уровень | **в 3.6 раз быстрее** |
| Использование диска | копирует файлы в каждый проект | **экономит до 60-70% места** через жёсткие ссылки |
| Структура `node_modules` | плоская (все пакеты на верхнем уровне) | строгая (только прямые зависимости видны) |
| Монорепы | поддерживает, но медленно | **индустриальный стандарт для монореп** |

**Как работает экономия pnpm?** pnpm хранит все пакеты в глобальном хранилище (`~/.pnpm-store`) и создаёт на них **жёсткие ссылки** в каждом проекте. Это значит, что один и тот же пакет физически хранится на диске один раз, но доступен во всех проектах.

**Установка pnpm:**

Способ 1 (рекомендуемый) — через corepack (встроен в Node.js):
```bash
corepack enable
corepack prepare pnpm@latest --activate
```

Способ 2 — глобально через npm:
```bash
npm install -g pnpm
```

**Проверка:**
```bash
pnpm -v
```

**Источники:**
- pnpm.io — официальный сайт.
- Сравнение pnpm vs npm: [linkedin.com/pulse](https://www.linkedin.com/pulse/pnpm-vs-npm-performance-dependency-resolution-compared-pawan-tripathi/).

### 5. Git — система контроля версий

**Что это?** Git отслеживает изменения в коде. Без него ты не сможешь работать в команде и не сможешь делать Pull Requests.

**Проверка установки:**
```bash
git --version
```

Если не установлен — скачай с git-scm.com.

**Базовая настройка (сделай один раз):**
```bash
git config --global user.name "Твое Имя"
git config --global user.email "твой@email.com"
```

**Источник:** git-scm.com — официальный сайт.
