## ТЕМА 0.5: DEEPFREEZE — УТИЛИТА С МАКСИМАЛЬНОЙ ТИПИЗАЦИЕЙ

### Цель
Написать функцию `deepFreeze<T>`, которая рекурсивно замораживает объект и все его вложенные объекты, а возвращает тот же объект, но с типом `DeepReadonly<T>`, где все свойства стали `readonly`. Это классическая задача для отработки **рекурсивных типов**, **условных типов** и **type guards** в TypeScript.

---

### 1. Теория: что такое `Object.freeze`?

- `Object.freeze(obj)` делает объект **неизменяемым**: нельзя добавлять, удалять или изменять свойства.
- В строгом режиме (он у нас включён) попытка изменения свойства выбросит ошибку.
- Однако TypeScript **не знает**, что объект заморожен, поэтому нам нужно создать тип, который отражает это.

---

### 2. Теория: рекурсивные типы

Рекурсивный тип — это тип, который ссылается сам на себя. Например, `DeepReadonly<T>`:
- Если `T` — объект, мы делаем все его свойства `readonly`, а для каждого значения снова применяем `DeepReadonly`.
- Если `T` — примитив (число, строка, boolean, null, undefined), мы просто возвращаем его.

**Синтаксис:**
```ts
type DeepReadonly<T> = {
  readonly [K in keyof T]: DeepReadonly<T[K]>;
};
```
Но этот вариант зациклится, если объект имеет циклические ссылки. Чтобы избежать этого, добавляем проверку на `object` и `null`:
```ts
type DeepReadonly<T> = T extends object
  ? { readonly [K in keyof T]: DeepReadonly<T[K]> }
  : T;
```
Здесь `T extends object` проверяет, является ли `T` объектом (но не `null` и не функцией). Однако функции тоже являются `object`, поэтому нам нужно их исключить.

---

### 3. Теория: type guards

Type guard — это функция, которая помогает TypeScript сузить тип. Например:
```ts
function isObject(value: unknown): value is Record<string, unknown> {
  return value !== null && typeof value === 'object';
}
```
Это говорит TypeScript: «если функция вернула `true`, то `value` — это объект».

### 4. Практическое задание

#### Шаг 1. Создай файлы
- `src/utils/deepFreeze.ts` — основная функция.
- `tests/deepFreeze.test.ts` — тесты.

#### Шаг 2. Напиши тип `DeepReadonly<T>`
- Используй условный тип: `T extends (...args: any[]) => any` для функций (оставляем без изменений).
- Затем проверь, является ли `T` объектом (но не `null`): `T extends object`.
- Если да, создай mapped type: `{ readonly [K in keyof T]: DeepReadonly<T[K]> }`.
- Для массивов добавь обработку: `T extends Array<infer U> ? ReadonlyArray<DeepReadonly<U>> : ...`.

#### Шаг 3. Напиши функцию `deepFreeze`
- Используй generic: `function deepFreeze<T>(obj: T): DeepReadonly<T>`.
- Напиши type guard `isObject`.
- Если `obj` не объект или `null` — верни его (без изменений).
- Получи все ключи объекта (через `Object.keys`).
- Для каждого ключа рекурсивно вызови `deepFreeze` на значении.
- После обхода всех ключей заморозь сам объект: `Object.freeze(obj)`.
- Верни объект.

#### Шаг 4. Напиши тесты
- Тест 1: плоский объект — проверь, что он заморожен (`Object.isFrozen`).
- Тест 2: вложенный объект — проверь, что вложенные свойства тоже заморожены.
- Тест 3: массив — проверь, что массив и его элементы заморожены.
- Тест 4: примитивы — проверь, что они возвращаются без изменений.
